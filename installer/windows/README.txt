AAI Instructor Report - Windows installation
=============================================

1. Unzip this package (right-click > Extract All).
2. Double-click Installer.bat.
   If Windows shows "Windows protected your PC",
   click "More info" then "Run anyway".
3. Follow the 3 clicks shown in the window:
   - Developer mode
   - Load unpacked
   - Ctrl+V in the address bar, Enter, Select Folder
4. Reload your Technical Instructor page on the AAI portal
   and click "My AAI report" at the bottom right.

Update: run Installer.bat from the new version,
then click "Reload" on the extension card.

Uninstall: chrome://extensions > Remove, then delete
the folder %LOCALAPPDATA%\AAIReport
